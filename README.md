# Tkinter Guessing Game Prototypes

This repository contains several standalone experiments with graphical number-guessing games. The Python scripts use Tkinter and have different interfaces and game rules; there is no single launcher that combines them.

## Run a prototype

Install Python 3 with Tkinter available, then run a script from this folder, for example:

```bash
python "Project 3.py"
```

Other entry points include `Program 7.py`, `Program 8.py`, `Project 5.py`, and `Project 6.py`. Run one at a time. `Program 7.py` also loads the included `Mark.png` image, so keep that asset beside the script.

These files are learning prototypes rather than a packaged application; each script's source is the reference for its specific controls and rules.
